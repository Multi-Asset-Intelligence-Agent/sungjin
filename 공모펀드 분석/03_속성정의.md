# 03. 속성 정의 — 공모펀드 온톨로지의 연결 구조

> 속성(Property)은 클래스 간의 관계(ObjectProperty)와
> 클래스-값 간의 연결(DatatypeProperty) 두 종류로 나뉜다.
> 원본 컬럼명과 온톨로지 속성명의 매핑을 명확히 기록한다.

---

## 1. ObjectProperty (클래스 ↔ 클래스 관계)

| 속성 URI | 도메인 | 범위 | 원본 컬럼 | 설명 |
|---------|--------|------|----------|------|
| `:managedBy` | :PublicFund | :AssetManagementCompany | `or_co_xtn_itt_cd` | 이 펀드를 운용하는 회사 |
| `:hasRiskGrade` | :PublicFund | :RiskGrade | `zrin_fd_ivst_risk_grd_nm` | 위험등급 연결 |
| `:investsIn` | :PublicFund | :InvestmentRegion | `fd_ivst_rgn_desc` | 투자 대상 지역 |
| `:followsBenchmark` | :PublicFund | :BenchmarkIndex | `bmrk_nm` | 추종 벤치마크 지수 |
| `:hasCustodian` | :PublicFund | :AssetManagementCompany | `trusc_xtn_itt_cd` | 수탁회사 (운용사와 구분) |

```turtle
:managedBy a owl:ObjectProperty ;
    rdfs:domain :PublicFund ;
    rdfs:range :AssetManagementCompany ;
    rdfs:label "운용회사"@ko ;
    rdfs:comment "해당 펀드를 운용하는 자산운용회사."@ko .

:hasRiskGrade a owl:ObjectProperty ;
    rdfs:domain :PublicFund ;
    rdfs:range :RiskGrade ;
    rdfs:label "위험등급"@ko ;
    rdfs:comment "제로인 기준 6단계 투자 위험등급."@ko .

:investsIn a owl:ObjectProperty ;
    rdfs:domain :PublicFund ;
    rdfs:range :InvestmentRegion ;
    rdfs:label "투자지역"@ko .

:followsBenchmark a owl:ObjectProperty ;
    rdfs:domain :PublicFund ;
    rdfs:range :BenchmarkIndex ;
    rdfs:label "벤치마크 추종"@ko .
```

## 2. DatatypeProperty (클래스 → 값)

### 2-1. 식별 속성

| 속성 URI | 범위 | 원본 컬럼 | 비고 |
|---------|------|----------|------|
| `:fundId` | xsd:string | `itm_no` | PK, 인스턴스 URI 생성에도 사용 |
| `:fundName` | xsd:string | `itm_nm` | 전체 펀드명 |
| `:fundShortName` | xsd:string | `itm_abrv_nm` | 약어명 |
| `:fssId` | xsd:string | `fss_itm_no` | 금융감독원 종목번호 |
| `:ksdId` | xsd:string | `ksd_itm_no` | 예탁원 종목번호 |
| `:stdId` | xsd:string | `std_itm_no` | 표준종목번호 |
| `:fundAttrCode` | xsd:string | `prfd_attr_cd` | 펀드별속성코드 (V101, M111 등) |

```turtle
:fundId a owl:DatatypeProperty ;
    rdfs:domain :PublicFund ;
    rdfs:range xsd:string ;
    rdfs:label "종목번호"@ko ;
    rdfs:comment "공모펀드 고유 식별자. itm_no 컬럼."@ko .

:fundName a owl:DatatypeProperty ;
    rdfs:domain :PublicFund ;
    rdfs:range xsd:string ;
    rdfs:label "종목명"@ko .
```

### 2-2. 수익률 속성 (선택적, Optional)

> 결측률이 높으므로 ontology에서 Optional 명시. 값 없는 인스턴스에는 트리플 미생성.

| 속성 URI | 범위 | 원본 컬럼 | 결측률 |
|---------|------|----------|--------|
| `:returnWeek1` | xsd:decimal | `fd_wk1_ern_r` | 27% |
| `:returnMonth1` | xsd:decimal | `fd_mm1_ern_r` | 28% |
| `:returnMonth3` | xsd:decimal | `fd_mm3_ern_r` | 28% |
| `:returnMonth6` | xsd:decimal | `fd_mm6_ern_r` | 30% |
| `:returnYear1` | xsd:decimal | `fd_yr1_ern_r` | 33% |
| `:returnYear2` | xsd:decimal | `fd_yr2_ern_r` | 39% |
| `:returnYear3` | xsd:decimal | `fd_yr3_ern_r` | 42% |
| `:returnYear5` | xsd:decimal | `fd_yr5_ern_r` | 47% |
| `:returnMonth18` | xsd:decimal | `fd_mm18_ern_r` | 34% |

```turtle
:returnYear1 a owl:DatatypeProperty ;
    rdfs:domain :PublicFund ;
    rdfs:range xsd:decimal ;
    rdfs:label "1년 수익률"@ko ;
    rdfs:comment "최근 1년 누적 수익률(%). 결측 가능."@ko .
```

### 2-3. 재무 속성

| 속성 URI | 범위 | 원본 컬럼 | 결측률 | 비고 |
|---------|------|----------|--------|------|
| `:netAsset` | xsd:decimal | `fd_nast_suma` | 13% | 단위: 원 |
| `:currency` | xsd:string | `curr_cd` | ~0% | KRW 등 |

```turtle
:netAsset a owl:DatatypeProperty ;
    rdfs:domain :PublicFund ;
    rdfs:range xsd:decimal ;
    rdfs:label "순자산"@ko ;
    rdfs:comment "펀드 순자산총액 (단위: 원). fd_nast_suma 컬럼."@ko .
```

### 2-4. 상태·분류 속성

| 속성 URI | 범위 | 원본 컬럼 | 값 예시 |
|---------|------|----------|---------|
| `:saleStatus` | xsd:string | `sale_yn` | "판매중", "판매완료" |
| `:miPoSaleStatus` | xsd:boolean | `thco_sale_yn` | Y/N → true/false |
| `:isHedgeFund` | xsd:boolean | `hdge_fd_yn` | 0/1 |
| `:isForeignFund` | xsd:boolean | `ofsfd_yn` | 0/1 |
| `:isForeignCurrencyBase` | xsd:boolean | `frc_bpr_itm_yn` | 0/1 |
| `:isHedged` | xsd:boolean | `exchdg_yn` | Y→true, N→false |
| `:dividendType` | xsd:string | `int_dvd_desc` | "배당", "이자" |
| `:investorType` | xsd:string | `pers_corp_desc` | "개인", "법인", "해당없음" |
| `:overseasFundType` | xsd:string | `ovrs_fd_desc` | "국내", "해외", "국내외혼합" |

```turtle
:saleStatus a owl:DatatypeProperty ;
    rdfs:domain :PublicFund ;
    rdfs:range xsd:string ;
    rdfs:label "판매여부"@ko ;
    rdfs:comment "'판매중' 또는 '판매완료'. sale_yn 컬럼."@ko .

:isHedged a owl:DatatypeProperty ;
    rdfs:domain :PublicFund ;
    rdfs:range xsd:boolean ;
    rdfs:label "환헤지 여부"@ko ;
    rdfs:comment "exchdg_yn = 'Y'이면 true. '00080008' 이상값은 null 처리."@ko .
```

```turtle

@prefix rdfs: <http://www.w3.org/2000/01/rdf-schema#> .

```
