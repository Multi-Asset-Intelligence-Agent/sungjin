# 04. 추론 규칙 (Axioms) — 관계에서 새 사실 도출

> OWL Axiom과 SPARQL/Cypher 기반 추론 규칙을 정의한다.
> "명시하지 않았지만 구조에서 자동으로 알 수 있는 사실"을 추론하는 것이 목표.

---

## 1. OWL Axiom 기반 추론

### 1-1. 위험등급 순서 추론 (TransitiveProperty)

```turtle
:riskierThan a owl:TransitiveProperty, owl:ObjectProperty ;
    rdfs:domain :RiskGrade ;
    rdfs:range  :RiskGrade ;
    rdfs:label "위험도 높음"@ko ;
    rdfs:comment "위험등급 간 순서 관계. 이행성(Transitive)으로 비교 가능."@ko .

:RiskGrade_VeryHigh  :riskierThan :RiskGrade_High .
:RiskGrade_High      :riskierThan :RiskGrade_SomewhatHigh .
:RiskGrade_SomewhatHigh :riskierThan :RiskGrade_Medium .
:RiskGrade_Medium    :riskierThan :RiskGrade_Low .
:RiskGrade_Low       :riskierThan :RiskGrade_VeryLow .
```

**도출 가능한 새 사실:**
- `:RiskGrade_VeryHigh :riskierThan :RiskGrade_Medium` (이행성 추론)
- "높은 위험 이상의 펀드" SPARQL 쿼리 작성 시 등급 열거 불필요

```sparql
# "보통 위험보다 위험한 등급을 가진 판매중 펀드"
SELECT ?fund WHERE {
    ?fund :saleStatus "판매중" ;
          :hasRiskGrade ?grade .
    ?grade :riskierThan :RiskGrade_Medium .
}
```

---

### 1-2. 서브클래스 포함 관계 (SubClassOf)

```turtle
:EquityFund rdfs:subClassOf :PublicFund .
:BondFund   rdfs:subClassOf :PublicFund .
:FoFund     rdfs:subClassOf :PublicFund .
```

**도출 가능한 새 사실:**
- `:EquityFund`의 인스턴스는 자동으로 `:PublicFund`의 인스턴스이기도 함
- "모든 공모펀드" 쿼리가 주식형·채권형 모두 포함

```sparql
# "모든 공모펀드" → 하위 클래스 자동 포함 (OWL 추론기 필요)
SELECT ?fund WHERE {
    ?fund a :PublicFund .
}
```

---

### 1-3. 역관계 (InverseProperty)

```turtle
:managedBy owl:inverseOf :manages .

:manages a owl:ObjectProperty ;
    rdfs:domain :AssetManagementCompany ;
    rdfs:range  :PublicFund ;
    rdfs:label "운용 펀드"@ko .
```

**도출 가능한 새 사실:**
- `fund:KR5174430032 :managedBy company:80021` 명시 시
  → `company:80021 :manages fund:KR5174430032` 자동 추론
- "이 운용사가 운용하는 펀드 목록" 쿼리가 별도 트리플 없이 가능

---

### 1-4. 해외 펀드 환헤지 규칙 (SWRL-style)

```
규칙: 해외 펀드(:overseasFundType = "해외") 이면서 환헤지(:isHedged = true) 이면
      → :isHedgedOverseasFund true 로 추론
```

```turtle
:isHedgedOverseasFund a owl:DatatypeProperty ;
    rdfs:domain :PublicFund ;
    rdfs:range xsd:boolean ;
    rdfs:comment "해외 투자 + 환헤지 적용 펀드 여부. 추론으로 도출."@ko .
```

SPARQL CONSTRUCT로 구현:
```sparql
CONSTRUCT {
    ?fund :isHedgedOverseasFund true .
}
WHERE {
    ?fund :overseasFundType "해외" ;
          :isHedged true .
}
```

---

### 1-5. 같은 벤치마크 추종 펀드 관계 (SameAs 확장)

```turtle
:sharesIndexWith a owl:SymmetricProperty, owl:ObjectProperty ;
    rdfs:domain :PublicFund ;
    rdfs:range  :PublicFund ;
    rdfs:label "같은 벤치마크 추종"@ko .
```

SPARQL CONSTRUCT로 도출:
```sparql
CONSTRUCT {
    ?fundA :sharesIndexWith ?fundB .
}
WHERE {
    ?fundA :followsBenchmark ?index .
    ?fundB :followsBenchmark ?index .
    FILTER(?fundA != ?fundB)
}
```

**활용 질문:**
- "이 펀드와 같은 벤치마크를 추종하는 다른 펀드는?"

---

### 1-6. 같은 운용사 펀드 관계

```turtle
:sameManagerAs a owl:SymmetricProperty, owl:ObjectProperty ;
    rdfs:domain :PublicFund ;
    rdfs:range  :PublicFund ;
    rdfs:label "같은 운용사 펀드"@ko .
```

SPARQL CONSTRUCT:
```sparql
CONSTRUCT {
    ?fundA :sameManagerAs ?fundB .
}
WHERE {
    ?fundA :managedBy ?company .
    ?fundB :managedBy ?company .
    FILTER(?fundA != ?fundB)
}
```

**활용 질문:**
- "미래에셋자산운용의 다른 펀드를 알려줘"

## 2. 그래프 탐색 기반 추론 (Neo4j Cypher)

Neo4j에서는 OWL 추론기 없이 Cypher로 직접 다단 관계를 탐색한다.

### 2-1. 위험등급 범위 탐색

```cypher
// "보통 위험 이상의 모든 펀드"
MATCH (g:RiskGrade)-[:RISKIER_THAN*]->(base:RiskGrade {name: "보통 위험"})
MATCH (f:PublicFund)-[:HAS_RISK_GRADE]->(g)
WHERE f.saleStatus = "판매중"
RETURN f.fundName, g.name
```

### 2-2. 운용사 → 펀드 → 위험등급 다단 탐색

```cypher
// "이 운용사의 위험등급별 펀드 분포"
MATCH (c:AssetManagementCompany {code: "40010"})-[:MANAGES]->(f:PublicFund)
MATCH (f)-[:HAS_RISK_GRADE]->(g:RiskGrade)
RETURN g.name, count(f) AS fundCount
ORDER BY g.gradeOrder
```

### 2-3. 벤치마크 기준 유사 펀드 추천

```cypher
// "이 펀드와 같은 벤치마크를 쓰는 채권혼합형 펀드"
MATCH (target:PublicFund {fundId: "KR5174430032"})-[:FOLLOWS_BENCHMARK]->(idx)
MATCH (similar:BondMixedFund)-[:FOLLOWS_BENCHMARK]->(idx)
WHERE similar.saleStatus = "판매중"
  AND similar.fundId <> target.fundId
RETURN similar.fundName, similar.returnYear1
ORDER BY similar.returnYear1 DESC
```

## 3. 추론 규칙 요약

| 규칙 | 유형 | 도출 사실 | 활용 질문 |
|------|------|----------|----------|
| 위험등급 이행성 | OWL TransitiveProperty | "높은 위험 이상" 자동 포함 | 위험 수준별 필터링 |
| 서브클래스 포함 | OWL SubClassOf | 주식형 ⊂ 공모펀드 | 전체 펀드 조회 |
| 역관계 | OWL InverseOf | 운용사→운용펀드 목록 | 운용사별 펀드 조회 |
| 해외+헤지 복합 | SPARQL CONSTRUCT | :isHedgedOverseasFund | 환위험 관리 펀드 조회 |
| 같은 벤치마크 | SymmetricProperty | :sharesIndexWith | 유사 전략 펀드 추천 |
| 같은 운용사 | SymmetricProperty | :sameManagerAs | 운용사 내 대안 추천 |
