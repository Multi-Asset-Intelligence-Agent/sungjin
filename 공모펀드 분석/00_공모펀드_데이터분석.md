## 0. 데이터 구조 핵심 요약


### PK 구조 중요 주의사항

`itm_no`(종목번호) 하나에 **평균 8.6개 행**이 존재한다.
같은 itm_no가 `prfd_attr_cd`(펀드별속성코드)와 `zrin_fd_ivst_risk_gcd`(위험등급코드) 조합으로 중복 등장하기 때문.
즉, 이 데이터는 **하나의 펀드 상품을 여러 판매 속성 기준으로 분해한 구조**다.

```
itm_no(11,139종) × prfd_attr_cd(228종) × zrin_fd_ivst_risk_gcd(7종)
= 최대 조합이 95,619행이 아닐 수 있음 → 실제 존재하는 조합만 수록
```

→ **RDB 적재 시 (itm_no, prfd_attr_cd)를 복합 PK로 사용할 것**

## 3. 전처리 필수 사항 정리

```python
#    (itm_no, prfd_attr_cd)가 진짜 복합 PK

#    NULL과 이상값이 있어 단독 사용 불가

RISK_GRADE_FIX = {
    "높은위험": "높은 위험",
    "보통위험": "보통 위험",

# 3. 위험등급 코드 이상값

# 5. 당사판매여부 이상값 (ksd_itm_no 형식 값)
df.loc[~df["thco_sale_yn"].isin(["Y", "N"]), "thco_sale_yn"] = None

# 6. 펀드유형 "06" 코드 변환
df.loc[df["or_attr_desc"] == "06", "or_attr_desc"] = "파생형"

df["or_co_xtn_itt_cd"] = df["or_co_xtn_itt_cd"].dropna().astype(int).astype(str)

# 8. 수익률 극단값 처리 (IQR 기준 또는 절대값 기준)
for col in ["fd_yr2_ern_r", "fd_yr3_ern_r", "fd_yr5_ern_r", "fd_mm18_ern_r"]:

    df.loc[df[col] > 1000, col] = None   # 1000% 이상은 오류로 간주

# 9. itm_eng_nm 한글 오염값 처리
import re
def is_english_or_mixed(s):
    if pd.isna(s): return True
    return bool(re.search(r"[a-zA-Z0-9]", str(s)))
# 순수 한글만 있는 경우 경고 로그

# 10. fss_itm_no / kofia_fd_ccd placeholder 명시화
df.loc[df["fss_itm_no"] == "000000000000", "fss_itm_no"] = None
```
